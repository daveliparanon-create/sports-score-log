# Sports Score - Live Sports Score Management System

A full-featured sports score management system with authentication and CRUD operations.

## Features

### Authentication (25%)
- User Registration (Sign Up)
- User Login
- Forgot Password functionality
- JWT-based authentication
- Session management

### CRUD Operations (50%)
- Create new matches
- Read/View all matches
- Update match scores and status
- Delete matches
- Search and filter matches

### JSON Server Integration (25%)
- Persistent data storage
- RESTful API endpoints
- User-specific data isolation

## Dashboard Features

1. **Welcome Section** - Personalized greeting
2. **Live Matches** - Real-time scores with LIVE badge
3. **Upcoming Matches** - Schedule with date and time
4. **Finished Games** - Final scores and winners
5. **Score Summary Cards** - Quick stats overview
6. **Search & Filter** - Search by team, filter by sport
7. **Match List Table** - Complete CRUD interface
8. **User Section** - User info and logout

## Color Coding
- Red = Live matches
- Green = Finished matches
- Gray = Upcoming matches
